EXPERIMENT 1: STUDY OF UML

AIM:
To study the various UML diagrams.

ALGORITHM / PROCEDURE:

1. Study the concept of Unified Modeling Language (UML).
2. Study the different types of UML diagrams.
3. Understand the symbols and notations used in each diagram.
4. Study how diagrams represent the structure and behaviour of a software system.

THEORY:
UML stands for Unified Modeling Language. It is a standard graphical language used to visualize, specify, construct and document software systems. It helps developers understand the system before implementation.

Types of UML diagrams:

1. Use Case Diagram – Represents actors and system functions.
2. Class Diagram – Represents classes, attributes, methods and relationships.
3. Object Diagram – Represents instances of classes.
4. Sequence Diagram – Represents messages exchanged between objects in time order.
5. Collaboration Diagram – Represents object interactions and message numbering.
6. Statechart Diagram – Represents states and transitions of an object.
7. Activity Diagram – Represents the workflow of a process.
8. Component Diagram – Represents software components and their dependencies.
9. Deployment Diagram – Represents the physical arrangement of hardware and software.

RESULT:
Thus, the study of various UML diagrams was completed successfully.

The system helps organize customer support, records and document processing.
